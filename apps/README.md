# apps/

End-user-facing applications built on top of the `packages/` platform. Unlike `packages/`, nothing here is
a library another package depends on — each subdirectory is a deployable/runnable product surface in its
own right.

| App | Description | Status |
|---|---|---|
| `dashboard` | The ORAM engineering dashboard (`docs/ORAM_SPECIFICATION_v1.md` is silent on UI implementation by design — see `ORAM_V3_MIGRATION_PLAN.md` Section 8 for the UX vision) | Scaffolded (README only) |
